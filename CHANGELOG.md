# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024

### Added
- Initial release of Autonomous Data Science AI
- Zero-hardcoded-rules agent architecture
- Dynamic capability discovery system
- Six specialized agents:
  - DataLoaderAgent
  - DataCleaningAgent
  - EDAAgent
  - VisualizationAgent
  - FeatureEngineeringAgent
  - MLAgent
- Natural language query processing with Google Gemini AI
- Smart query suggestions based on dataset context
- Interactive Streamlit web interface
- Support for CSV and Excel file formats
- 10+ machine learning algorithms
- Comprehensive data visualization capabilities
- Automatic preprocessing and feature engineering
- Real-time conversation history
- Downloadable results (CSV, plots)

### Features
- Complete data science pipeline automation
- Intelligent task dependency handling
- Context-aware query recommendations
- Multi-model ML comparison
- Feature importance analysis
- Correlation analysis
- Missing value handling
- Outlier detection and removal
- Categorical encoding
- Feature scaling and normalization

### Security
- Secure API key handling
- Local data processing
- No external data storage
